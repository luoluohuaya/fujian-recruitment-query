# 福建招考岗位与成绩查询（2022—2026）

为福建考生提供一个集中查询岗位与公开笔试成绩的选岗工具。

## 项目背景

国考、省考和事业单位招聘的信息通常分散在各级招录机关、人社部门、学校、医院等网站。岗位表、报名条件、笔试成绩和资格复审或面试名单往往分别发布，同一个地区还可能有年度招聘、补充招聘和专项招聘等不同批次。考生在多个网页和附件之间反复查找、核对专业条件与历史分数，需要花费不少时间，也容易混淆不同年份和批次。

这个项目希望把已收集的福建地区国考、省考和事业单位岗位信息与公开的笔试成绩整理到一个查询页面。考生可以从自己的年份、地区和专业出发，查看岗位要求及对应批次的公开成绩，收藏感兴趣的岗位，并把多个岗位放在一起比较。项目持续补充和核对资料，帮助考生更方便地缩小选岗范围；最终报考条件及成绩口径仍应以招录机关发布的原始公告为准。

## 在线使用与离线使用

- **在线查询**：打开[在线查询网页](https://luoluohuaya.github.io/fujian-recruitment-query/)即可使用。首次载入的数据量较大，请耐心等待。
- **离线查询**：直接下载[福建招考岗位与成绩查询离线版（HTML）](https://github.com/luoluohuaya/fujian-recruitment-query/releases/download/v2026.10.28/_.html)到电脑（GitHub 显示的附件文件名为 `_.html`，内容与原始离线版一致）；也可以在[发行作品下载页](https://github.com/luoluohuaya/fujian-recruitment-query/releases/latest)的附件中下载，双击用新版 Chrome 或 Microsoft Edge 打开；首次加载需要等待解压。岗位筛选不需要后端服务，打开岗位来源、成绩来源和百度地图时需要联网。
- 网页内置的是数据快照，**不会自动同步官方最新公告**。更新后需要重新访问新版网页或下载新版文件。

## 如何选岗

1. 选择年份和考试类型；也可以保留全部。
2. 按福建省、市、县区选择地区。不选县区可查询整个城市，只选省也可以查询。
3. 根据需要选择实际招聘批次、事业单位类别、成绩与条件收集状态，或输入单位、岗位、代码关键词。
4. 在“筛选专业”中搜索并勾选一个或多个专业，再点击“查询岗位”。专业选项来自已收集的岗位要求，具体资格、专业方向及类别范围仍须查看原表。
5. 查看卡片上的岗位要求与公开前三名笔试成绩；点击展开，可查看公开前十、单科与更多条件。
6. 对感兴趣的岗位点击“收藏”或“加入对比”，再打开“我的收藏”或“岗位对比”进行查看。

## 功能说明

### 筛选与查找

- **年份与类型**：按官方考试命名归年，筛选 2022—2026 年国考、省考和事业单位。
- **地区联动**：按省、市、县区查询；地区匹配方式可在页面中选择，具体工作地点、单位地区及公告地区以页面标识为准。
- **实际招聘批次与类别**：按已收录的招聘批次、事业单位招聘类别筛选；不同招聘、补充招聘、专项招聘应分别核对。
- **成绩与条件状态**：筛选已有个人笔试成绩、成绩待补、仅公开部分名单、进面资料或岗位条件待补等状态。
- **专业搜索与多选**：专业可搜索、多选，匹配所选专业中的任一项。专业筛选不等同于报考资格认定。
- **单选与多选切换**：默认除专业外每个筛选项单选；点击筛选卡片右上角按钮后，年份、考试类型、城市、县区、批次、类别和状态等可多选。同一筛选项按任一所选值匹配，不同筛选项共同生效。切回单选时，除专业外保留最近一次选择。
- **关键词及翻页**：可通过单位、岗位或代码查找，并翻页浏览结果。

### 岗位与成绩

- **卡片速览**：展示单位、岗位、招录人数、专业、学历、学历类别、学位、地区及已收录的公开前三名笔试成绩。
- **展开详情**：查看公开前十、其他岗位条件及进面资料；遇到并列名次按页面显示。行测、申论及其他已公开单科分别显示，缺失单科标记未取得。
- **公开范围与成绩口径**：成绩可能来自全体公开成绩、官方前十、公开入围名单或其他部分名单。部分名单中的前十不代表全岗位实际前十；首次进面线、调整后进面线和公开入围名单最低笔试分应按标注区分。不同年份、试卷及折算方式的分数不宜直接横比。
- **缺失和特殊情况**：未取得的数据显示待补或未取得；免笔试、取消等情形以岗位标识为准。不能把未公开的成绩当作 0，也不能把面试分、综合分或笔试合格线当作笔试进面线。
- **来源按钮**：岗位来源、成绩来源以及展开成绩右侧的原件链接可跳转到已收录的来源；转载或待核验资料以页面标识为准。

### 排序、导出、收藏与对比

- **成绩排序**：点击排序按钮依次切换为从低到高、从高到低、恢复默认。按岗位公开成绩中的最高分排序；只有最低进面分时使用该分，没有可用成绩的岗位排在最后。
- **导出当前筛选结果**：将当前筛选结果导出为文件，方便进一步查看；导出的是当前筛选范围而非完整原始数据库。
- **收藏**：点击卡片上的“收藏”，可跨筛选查看；收藏面板支持搜索、展开和取消收藏。
- **岗位对比**：点击多个卡片上的“加入对比”，打开独立对比面板。成绩和进面资料优先显示，之后可比较招聘批次、人数、专业、学历、学位、工作地点及其他限制；可选择“仅看条件差异”，也可逐项移除或清空对比。
- **保存位置**：收藏与对比保存在当前浏览器本地，不需要登录；清理浏览器数据、换浏览器或换设备可能使记录不可见。在线网址与本地文件通常各自保存，不能自动同步。

### 工作地点地图

点击卡片上的“百度地图”，确认后按已收录的具体单位名称或明确门牌地址在地图中查找；如公告列出多个地址，可选择查看。地图可以辅助查看街景及附近车站，实际办公地点、同名单位、校区和地图结果仍需结合原公告核对；如百度要求安全验证，请按页面提示操作。

## 数据范围与使用提示

目标范围为福建地区 2022—2026 年国考、省考、事业单位招聘，事业单位包含综合、教师、医疗等类别及省属、各地市、县区和平潭。**当前资料尚未完整覆盖全部地区、岗位和批次，部分岗位条件、个人成绩及进面资料仍待补充。**

当前页面是 2026 年 10 月 28 日数据快照：已收录 67,059 个岗位，数据库中有 679,461 条笔试记录。网页展示与岗位关联的已公开资料，并非每个岗位都有完整前十。来源可能包括官方公告、原始附件及明确标记的转载资料；请点击原件核对招录对象、学历专业、工作地点、成绩范围和最新通知。

本项目仅供信息整理和选岗参考，不代表招录机关，也不构成报考资格、录用或分数预测承诺。报名、资格审查、成绩及最终录用均以对应官方公告为准。
